# Proyecto RAG
### Cómo ejecutar en un dev container

Tener instalado la extension de dev containers

Click en boton azul abajo a la izquierda de vs code, "reabrir en contenedor"

Adentro del contenedor, se puede usar el debugger de python para correr la aplicacion de chainlit.

Si se hacen cambios en el compose, al entrar en el dev container, se debe volver a tocar en el boton azul y clickear "reconstruir contenedor"
